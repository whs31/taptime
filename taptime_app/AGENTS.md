# TapTime Android

Этот файл фиксирует архитектуру Android-приложения по прямому поручению владельца. Последующие изменения требуют согласования владельца.

- Работать только в существующем репозитории. Не выполнять commit, push, публикацию, подключение телефона или ADB без отдельного разрешения.
- Следовать утверждённым manifest.toml и api-contract.toml. Не добавлять рукописные файлы, публичные классы или методы вне согласованного перечня. Не менять контракты ради прохождения проверки.
- Не изменять соседние модули. Исключение: согласованные Cargo.toml, src/lib.rs, src/api.rs, src/auth.rs и tests/api_mutations.rs общего taptime_client.
- Направление вызовов: Kotlin repositories → TapTimeGateway → UniFFI → Rust SDK → taptime_client → сервер. Расчёты времени и отчётов выполняются в Rust с использованием реальных серверных моделей.
- AppContainer собирает зависимости без DI-фреймворка. ViewModel обращается к repositories, не к Rust напрямую.
- Не использовать Tauri, WebView, Flutter, React Native, Kotlin HTTP API, Linux daemon, Unix-сокеты, systemd или XDG в Android.
- Токен SDK хранится только в памяти. Android защищает сохраняемый токен Keystore; пароль не сохраняется. Секреты исключаются из Room, логов и backup.
- Записывающие тесты используют только локальные реализации сервера. Не выполнять реальные мутации production.
- Мутации с неопределённым исходом не повторять автоматически; сначала перечитать фактическое состояние. Один координатор обслуживает UI и виджеты.
- Семь виджетов используют RemoteViews, Canvas и подходящий Chronometer. Настройки изолированы по appWidgetId; logout очищает персональные данные.
- Не добавлять комментарии в исходный код, кроме необходимых Doxygen-комментариев критически важных функций. Не добавлять неутверждённые Python-тесты.
- Отчёты вести по-русски и разделять VERIFIED, INFERRED, BLOCKED, NOT RUN. Сборка не доказывает успешный запуск.
- Архитектурные препятствия собирать в один запрос после выполнения независимой работы; не скрывать их заглушками.
